Losetas pregeneradas

Las losetas ya no contienen nodos A/B. Sólo algunos ambientes traen un puesto de guardia G; la ronda se crea cuando el banco ya existe.

Mesa

Una loseta nueva debe conectar por puerta con el banco y todos los bordes vecinos deben coincidir: puerta con puerta, pared con pared. Al editar el banco se borran las patrullas para volver a calcularlas.

La recepción es la loseta inicial obligatoria. Construí desde ahí o generá un banco completo.
