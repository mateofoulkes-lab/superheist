# SuperHeist

Prototipo y herramientas de diseño para **SuperHeist / SuperAtraco**.

## Toolbox

El archivo raíz `index.html` descubre automáticamente las herramientas publicadas en `/tools` del branch `main`.

Cada herramienta vive en:

```
tools/
  nombre-de-la-tool/
    index.html
    tool.json
```

`tool.json` contiene título, estado y descripción para la portada.

### Herramientas actuales

- **Constructor de Banco** — montaje manual de losetas modulares con rotación y validación de puertas/paredes.

> Para verlo como sitio web, se puede activar GitHub Pages sirviendo desde la raíz de `main`.
